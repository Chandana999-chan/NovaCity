# NovaCity – Fictional City Simulator

NovaCity is an interactive digital twin prototype that simulates
urban infrastructure, transportation, traffic disruptions and
policy interventions.

## Member 2 Responsibilities

- Interactive Streamlit dashboard
- City road network visualisation
- Road closure simulation
- Accident simulation
- Flood simulation
- Public transport policy interventions
- Travel time analytics
- Commuter route analysis
- Scenario comparison

## Technology Stack

- Python
- Streamlit
- NetworkX
- Plotly
- Pandas
- NumPy
